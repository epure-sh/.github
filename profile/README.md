### Product

| Repository | What it is |
|---|---|
| [**epure**](https://github.com/epure-sh/epure) | Error tracking engine: Rust + PostgreSQL 16, two containers, AGPL-3.0 |
| [`@epure-sh/mcp`](https://www.npmjs.com/package/@epure-sh/mcp) · [`@epure-sh/cli`](https://www.npmjs.com/package/@epure-sh/cli) | Your coding agent reads and triages issues. Apache-2.0 |

```bash
git clone https://github.com/epure-sh/epure.git
cd epure
docker compose up -d
# → http://localhost:8080
```

Errors only: no tracing, replay or profiling. Image: [`ghcr.io/epure-sh/epure`](https://github.com/epure-sh/epure/pkgs/container/epure) · [Latest release](https://github.com/epure-sh/epure/releases/latest)
