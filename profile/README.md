### Product

| Repository | What it is |
|---|---|
| [**epure**](https://github.com/epure-sh/epure) | Self-hosted exception tracker — Rust + PostgreSQL 16, Apache 2.0 |

```bash
git clone https://github.com/epure-sh/epure.git
cd epure
docker compose up -d
# → http://localhost:8080
```
