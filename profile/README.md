# epure.sh

Exception-only error monitoring for small SaaS teams.

When production throws, you get a grouped issue with a stack you can read. Essentials only — issues, grouping, releases, source maps, calm alerts.

**Self-host light · Sentry SDK compatible · flat bills**

- Two containers (~82 MiB idle) — Rust + PostgreSQL 16
- Keep your `@sentry/*` SDKs — change the DSN
- [Quickstart →](https://github.com/epure-sh/epure/blob/main/docs/QUICKSTART.md)
